# PDF source

Query text, tables, images, and document structure from local PDF documents using Coral SQL. Each row represents one page from a PDF with rich extraction via PyMuPDF.

## Prerequisites

- Python 3.8+ with PyMuPDF installed
- Coral (latest)

```bash
pip install pymupdf
```

## Setup

### 1. Convert PDFs to JSONL

Use the included `scripts/pdf-to-jsonl.py` converter:

```bash
# Process all PDFs in a directory
python sources/community/pdf/scripts/pdf-to-jsonl.py --dir ~/pdfs/

# Process specific files
python sources/community/pdf/scripts/pdf-to-jsonl.py --files doc1.pdf doc2.pdf

# Specify output path (default: ~/.coral/pdf/pages.jsonl)
python sources/community/pdf/scripts/pdf-to-jsonl.py --dir ~/pdfs/ --out ~/.coral/pdf/pages.jsonl

# Scan recursively
python sources/community/pdf/scripts/pdf-to-jsonl.py --dir ~/pdfs/ --recursive
```

### 2. Add the source

```bash
coral source add --file sources/community/pdf/manifest.yaml
```

### 3. Query

```sql
-- List all indexed PDFs
SELECT DISTINCT file_name FROM pdf.pages;

-- Full text of a specific document
SELECT page, text FROM pdf.pages
WHERE file_name = 'resume.pdf'
ORDER BY page;

-- Structured markdown (headings, bold, italic preserved)
SELECT page, markdown FROM pdf.pages
WHERE file_name = 'report.pdf'
ORDER BY page;

-- Search across all documents
SELECT file_name, page FROM pdf.pages
WHERE text LIKE '%machine learning%';

-- Find pages with tables
SELECT file_name, page FROM pdf.pages
WHERE tables LIKE '%"header"%';

-- Document metadata
SELECT file_name, metadata FROM pdf.pages;

-- Text blocks with position and font info
SELECT blocks FROM pdf.pages
WHERE file_name = 'resume.pdf';
```

## Tables

### `pages`

Text, tables, images, and structure extracted from PDF documents, one row per page. Generated by the `pdf-to-jsonl.py` converter script using PyMuPDF.

**Columns**

| Column | Type | Nullable | Description |
|--------|------|----------|-------------|
| `file_name` | Utf8 | false | File name of the source PDF (e.g. resume.pdf). |
| `path` | Utf8 | false | Absolute filesystem path to the source PDF. |
| `page` | Int64 | false | Page number within the PDF (1-indexed). |
| `page_count` | Int64 | false | Total number of pages in the document. |
| `text` | Utf8 | false | Full plain text content extracted from the page. |
| `markdown` | Utf8 | false | Structured markdown preserving headings, bold, and italic formatting. |
| `blocks` | Json | false | JSON array of text blocks with position (x0,y0,x1,y1), font name, size, bold, italic, and color. |
| `tables` | Json | false | JSON array of extracted tables with header row and data rows. |
| `images` | Json | false | JSON array of image references with width, height, and xref. |
| `metadata` | Json | true | PDF document metadata (author, title, subject, producer, creation date, etc.). |

## Extraction details

- **Text**: Full page text via `page.get_text("text")` — best for SQL search and full-content retrieval.
- **Markdown**: Reconstructed from block-level analysis — headings sized by font size + bold, italic text preserved, bullet points kept.
- **Blocks**: Each text span on the page with precise bounding box (`x0,y0,x1,y1`), font name, font size, bold/italic flags, and color. Use this for layout-aware analysis.
- **Tables**: Extracted via `page.find_tables()` — returns header rows and data rows with bounding box. Pages without tables have an empty array.
- **Images**: References to embedded images with width, height, and xref (cross-reference number). Pages without images have an empty array. Actual image binary data is not stored in the JSONL to keep file sizes manageable.

## Limitations

- The source reads from pre-converted JSONL files — re-run `pdf-to-jsonl.py` when PDFs change.
- Text extraction quality depends on the PDF format. PyMuPDF handles most PDF types robustly.
- Scanned PDFs (image-only, no text layer) will have empty `text` — use OCR tools (Tesseract, OCRmyPDF) before conversion.
- Table extraction uses PyMuPDF's built-in table detection, which works well for bordered tables but may miss borderless tables.
- Image binary data is not embedded in the JSONL output — only references (xref, dimensions).

## Source scope

- Reads JSONL files from `~/.coral/pdf/*.jsonl`.
- Provides read-only access to extracted PDF text, markdown, blocks, tables, images, and metadata.
- No required filters — all columns are queryable directly.
- 1 declared test query confirms the source is connected and pages are readable.
